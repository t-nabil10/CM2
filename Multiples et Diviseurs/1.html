🔢 Séance 1 : Les multiples

📖 1. Définition

📌 Définition Un multiple d'un nombre est le résultat de la multiplication de ce nombre par un nombre entier : 0, 1, 2, 3, 4…
7 × 4 = 28 → 28 est un multiple de 7

⭐ 2. Propriétés

📏 Règles
  • Un nombre a une infinité de multiples.
  • 0 est un multiple de tous les nombres (a × 0 = 0).
  • Un nombre est un multiple de lui-même (a × 1 = a).

🔍 3. Reconnaître un multiple

🧭 Méthode Pour savoir si b est un multiple de a : je cherche un nombre entier qui, multiplié par a, donne b. Ou bien je divise b par a : si le reste est 0, b est un multiple de a.
✅ Critères
Un nombre est un multiple de…quand…
2son dernier chiffre est 0, 2, 4, 6 ou 8
3la somme de ses chiffres est un multiple de 3
(123 : 1 + 2 + 3 = 6)
5son dernier chiffre est 0 ou 5
9la somme de ses chiffres est un multiple de 9
(378 : 3 + 7 + 8 = 18)

✏️ 4. Exemples corrigés

Exemple 1. Écris les multiples de 7 inférieurs à 50.

7 × 0 = 0 ; 7 × 1 = 7 ; 7 × 2 = 14 ; 7 × 3 = 21 ; 7 × 4 = 28 ; 7 × 5 = 35 ; 7 × 6 = 42 ; 7 × 7 = 49

Les multiples de 7 inférieurs à 50 sont : 0, 7, 14, 21, 28, 35, 42, 49.

Exemple 2. a) 56 est-il un multiple de 8 ?
b) 45 est-il un multiple de 6 ?

a) 8 × 7 = 56. Oui, 56 est un multiple de 8.

b) 6 × 7 = 42 et 6 × 8 = 48. Le nombre 45 est entre 42 et 48. Non, 45 n'est pas un multiple de 6.

Exemple 3. Parmi 135, 246, 378 et 540, quels nombres sont des multiples de 2 ? de 3 ? de 5 ? de 9 ?

Sommes des chiffres : 135 → 1 + 3 + 5 = 9 ; 246 → 2 + 4 + 6 = 12 ; 378 → 3 + 7 + 8 = 18 ; 540 → 5 + 4 + 0 = 9.

  • Multiples de 2 (dernier chiffre pair) : 246, 378, 540.
  • Multiples de 3 (somme multiple de 3) : 135, 246, 378, 540.
  • Multiples de 5 (dernier chiffre 0 ou 5) : 135, 540.
  • Multiples de 9 (somme multiple de 9) : 135, 378, 540.
